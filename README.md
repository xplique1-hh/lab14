**Вариант 26. Локальные максимумы.**
Реализуйте `int countLocalMaxima(const int *a, int n)`. Локальным максимумом считайте элемент, который строго больше своего левого и правого соседей. Первый и последний элементы не проверяйте. Проверьте массивы без локальных максимумов и с несколькими пиками.

## 1. Алгоритм и блок-схема

   - Вывести количество найденных локальных максимумов.
5. В функции `countLocalMaxima`:
   - Инициализировать счетчик `count = 0`.
   - Организовать цикл от `i = 1` до `n - 2` (исключая крайние элементы).
   - Проверить условие: `a[i] > a[i - 1]` **И** `a[i] > a[i + 1]`.
   - Если условие выполняется, увеличить `count` на 1.

## 2. Реализация программы

```c
#include <stdio.h>

#define MAX 1000

int countLocalMaxima(const int* a, int n) {
    int count = 0;
    for (int i = 1; i < n - 1; i++) {
        if (a[i] > a[i - 1] && a[i] > a[i + 1]) {
            count++;
        }
    }
    return count;
}

int main(void) {
    int n;
    int a[MAX];
    
    printf("Введите n: ");
    if (scanf("%d", &n) != 1 || n <= 0 || n > MAX) {
        printf("Некорректное n (должно быть от 1 до %d)\n", MAX);
        return 1;
    }
    
    for (int i = 0; i < n; i++) {
        printf("a[%d] = ", i);
        scanf("%d", &a[i]);
    }
    
    int result = countLocalMaxima(a, n);
    printf("Количество локальных максимумов: %d\n", result);
    
    return 0;
}
```
